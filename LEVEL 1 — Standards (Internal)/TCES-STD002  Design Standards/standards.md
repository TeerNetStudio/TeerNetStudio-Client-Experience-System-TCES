**Owner:** TeerNetStudio

---

# Purpose

This document establishes the visual design standards used throughout the TeerNetStudio Client Experience System (TCES).

Its purpose is to ensure every document, presentation, proposal, invoice, contract, and PDF reflects a consistent visual identity.

Consistency builds trust.

Professionalism builds confidence.

Together, they create a recognizable TeerNetStudio experience.

---

# Standard 1 — Design Philosophy

Every TCES document should feel:

* Professional
* Minimal
* Modern
* Elegant
* Easy to Read
* Print Friendly
* Accessible

Documents should prioritize clarity over decoration.

---

# Standard 2 — Visual Principles

Every design decision should satisfy these questions:

✅ Does it improve readability?

✅ Does it improve understanding?

✅ Does it reduce visual clutter?

If the answer is **No**, remove it.

---

# Standard 3 — Brand Personality

Every document should communicate:

```text
Professional

↓

Trustworthy

↓

Organized

↓

Friendly

↓

Premium
```

Never:

* Flashy
* Over-designed
* Childish
* Difficult to read
* Filled with unnecessary graphics

---

# Standard 4 — Color System

### Primary Color

TeerNetStudio Black

---

### Secondary Color

Pure White

---

### Accent Color

Brand Red

(Reserved for highlights, warnings, important actions, and branding.)

---

### Status Colors

🟢 Success

🟡 Warning

🔴 Action Required

🔵 Information

⚪ Neutral

These colors should remain consistent across all documents.

---

# Standard 5 — Typography

Maximum font families:

**Two**

Recommended:

Heading Font

Body Font

Rules:

* Headings should establish hierarchy.
* Body text should maximize readability.
* Decorative fonts are prohibited in official documents.

---

# Standard 6 — Document Hierarchy

Every page should clearly distinguish:

Level 1

Document Title

↓

Level 2

Section

↓

Level 3

Subsection

↓

Body Text

↓

Notes

↓

Footer

---

# Standard 7 — White Space

White space is intentional.

Never fill empty space simply because it exists.

Margins, spacing, and breathing room improve comprehension.

---

# Standard 8 — Grid System

All documents should follow a consistent layout grid.

Examples:

* Consistent margins
* Consistent table widths
* Consistent alignment
* Consistent spacing between sections

---

# Standard 9 — Tables

Tables should:

* Have consistent padding
* Use clear headers
* Avoid unnecessary borders
* Maintain equal spacing

Tables exist to improve readability—not decoration.

---

# Standard 10 — Icons

Icons should:

* Use one icon style
* Be minimal
* Support content
* Never replace text completely

---

# Standard 11 — Callout Boxes

Callouts should have a consistent purpose.

💡 TeerTip

Helpful recommendations.

⚠️ Important

Critical information.

📌 Note

Additional context.

Never invent new styles unnecessarily.

---

Every major document should include:

Document ID

Optional:

Brand Motto

# Standard 13 — Header

Each page should display:

Document Name

Document ID

Version

# Standard 15 — Signature Blocks

All signature sections should follow one layout throughout TCES.

Client

Representative

Date

Signature

No redesigns between documents.

---

# Standard 16 — Status Badges

Standard badges:

Draft

Pending

Approved

Active

Completed

Archived

Cancelled

Same appearance across every document.

---

# Standard 17 — QR Codes

QR Codes should always appear in a consistent position.

Preferred:

Bottom Right

Minimum clear space maintained.

Never distort QR Codes.

---

# Standard 18 — Document References

Cross-document references should always use:

```text
TNS-P001

Project Scope

or

Refer:

TNS-001
Creative Partnership Agreement
```

Never use inconsistent naming.

---

# Standard 19 — Images

Images should:

* Support content
* Be high quality
* Have consistent spacing
* Never stretch
* Maintain aspect ratio

---

# Standard 20 — PDF Export

Before exporting:

✓ Check spelling

✓ Verify page numbering

✓ Verify hyperlinks

✓ Embed fonts (if licensing permits)

✓ Optimize file size

✓ Test printing

✓ Test mobile readability

---

# Standard 21 — Accessibility

Documents should:

* Use sufficient contrast
* Avoid color-only indicators
* Use readable font sizes
* Maintain logical reading order
* Be printable in grayscale where possible

---

# Standard 22 — Naming Convention

Export format:

```text
TNS-C001_Quotation_v1.0.pdf

TNS-C002_Invoice_2026-001.pdf

TNS-D001_ProjectDelivery.pdf
```

Avoid:

```text
quotation_final2_latest_REAL.pdf
```

😂

---

# Standard 23 — Print Standards

Official PDFs should support:

* A4
* Letter (optional)
* High Resolution
* Print Margins
* CMYK where required

---

# Standard 24 — Consistency Rule

A client opening any TCES document should immediately recognize:

"This is a TeerNetStudio document."

Without needing to see the logo.

Consistency creates identity.
